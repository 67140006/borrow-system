# ระบบยืม-คืนอุปกรณ์และพัสดุ
### สโมสรนิสิตคณะรัฐศาสตร์ มหาวิทยาลัยบูรพา

ระบบบริหารจัดการการยืม-คืนอุปกรณ์สำหรับสโมสรนิสิต พัฒนาด้วย HTML, CSS (Tailwind), และ JavaScript ล้วนๆ ไม่ต้องติดตั้ง server หรือ dependencies ใดๆ

---

## 🚀 วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วย browser ได้เลย ไม่ต้องติดตั้งอะไรทั้งนั้น

หรือดูผ่าน GitHub Pages ได้เลยหลัง deploy

---

## ✨ ฟีเจอร์

- **หน้ายืม-คืนอุปกรณ์** — เลือกจำนวน, กรอกข้อมูลผู้ยืม, แนบหลักฐาน
- **คลังอุปกรณ์** — แสดงจำนวนของที่มีและถูกยืมไปแบบ real-time
- **ประวัติและสถานะ** — ตรวจสอบสถานะคำขอยืม-คืนทั้งหมด
- **แผงควบคุมแอดมิน** — อนุมัติหรือปฏิเสธคำขอ (สลับสิทธิ์ได้)

---

## 🗂️ โครงสร้างไฟล์

```
.
├── index.html      # ไฟล์หลัก (ทุกอย่างอยู่ในนี้)
└── README.md       # ไฟล์นี้
```

---

## 🛠️ เทคโนโลยีที่ใช้

| เทคโนโลยี | รายละเอียด |
|---|---|
| HTML5 | โครงสร้างหน้าเว็บ |
| Tailwind CSS (CDN) | จัดสไตล์ |
| Font Awesome (CDN) | ไอคอน |
| Google Fonts: Sarabun | ฟอนต์ภาษาไทย |
| Vanilla JavaScript | ลอจิกทั้งหมด |

> ข้อมูลทั้งหมดเก็บใน memory (JavaScript array) ยังไม่มี backend/database

---

## 📌 การ Deploy บน GitHub Pages

1. Push ไฟล์ขึ้น repository
2. ไปที่ **Settings → Pages**
3. เลือก Source: `main` branch, `/ (root)`
4. กด Save แล้วรอสักครู่

เว็บจะพร้อมใช้งานที่ `https://<username>.github.io/<repo-name>/`
